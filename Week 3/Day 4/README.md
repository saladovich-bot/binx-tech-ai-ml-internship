# Day 4 — Trees, Forests, SVMs & k-NN

## Learning Objectives

- Train and interpret decision trees and random forests, including feature importances
- Train SVM and k-NN classifiers and explain how each makes decisions
- Compare multiple classifiers fairly on the same train/test split and metric

## What Was Done

- Trained a decision tree, random forest, SVM, and k-NN on the same train/test split from Day 3
- Evaluated all four models with the same metric (F1-score) and assembled the results into one comparison table
- Reported the random forest's top feature importances and interpreted them
- Identified the best-performing model for the dataset and explained, in Markdown, why it likely won

## Dataset

Same classification dataset used on Day 3 (Titanic)

## Tools Used

Scikit-learn (tree, ensemble, svm, neighbors) • Pandas • Jupyter Notebook
