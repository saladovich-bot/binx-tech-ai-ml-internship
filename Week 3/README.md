# Week 3 — Supervised Learning: Regression & Classification with Scikit-learn

Week 3 (Phase 2: Core ML Training) of the internship program: training the first real machine learning models. Interns build regression models to predict numbers and classification models to predict categories — linear and logistic regression, decision trees, random forests, SVMs, and k-NN — all using the Scikit-learn API.

**Prerequisite:** Weeks 1–2 completed (Python/NumPy/Pandas fluency, math foundations, EDA methodology).

## Learning Objectives

- Explain what supervised learning is and distinguish regression from classification
- Split data correctly into training and test sets and explain why this prevents misleading results
- Train, predict with, and evaluate a linear regression model and interpret its coefficients and error
- Train and evaluate a logistic regression classifier and read a confusion matrix
- Train and compare tree-based models (decision trees, random forests) plus SVM and k-NN
- Assemble a complete supervised-learning mini-project: EDA → preprocessing → model → evaluation

## Deliverables

- A workflow notebook demonstrating the features/target split and a reproducible train/test split
- A linear regression notebook with interpreted coefficients and MAE/RMSE/R² evaluated against a baseline
- A logistic regression notebook with a confusion matrix, precision/recall/F1, and AUC-ROC
- A model-comparison notebook evaluating decision tree, random forest, SVM, and k-NN on one split
- The Week 3 end-to-end mini-project: a trained, evaluated model with full pipeline documentation
- All Week 3 notebooks committed to the intern's GitHub repository with clear commit messages

## Tech Stack

Python 3.10+ • Scikit-learn (LinearRegression, LogisticRegression, tree, ensemble, svm, neighbors) • Pandas • Matplotlib • Seaborn • Jupyter Notebook • Git & GitHub
