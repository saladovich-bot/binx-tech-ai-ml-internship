# Day 3 — Logistic Regression & Classification Metrics

## Learning Objectives

- Train a logistic regression classifier and obtain class probabilities
- Explain why accuracy alone is misleading on imbalanced data
- Read a confusion matrix and compute precision, recall, F1, and AUC-ROC

## What Was Done

- Trained a `LogisticRegression` model on a classification dataset (titanic)
- Generated predictions and produced the confusion matrix
- Computed precision, recall, and F1 with `classification_report`, and interpreted each
- Decided whether precision or recall matters more for this problem and justified the choice
- Computed the AUC-ROC and documented what it says about the model

## Dataset

Titanic dataset

## Tools Used

Scikit-learn (LogisticRegression) • Pandas • Matplotlib • Jupyter Notebook
