# Day 2 — Linear Regression

## Learning Objectives

- Train a linear regression model and generate predictions
- Interpret the model's coefficients and intercept
- Evaluate a regression model with MAE, RMSE, and R² against a baseline

## What Was Done

- Trained a `LinearRegression` model on a regression dataset (house prices)
- Reported the model's coefficients and identified the feature with the strongest effect
- Evaluated the model on the test set with MAE, RMSE, and R²
- Compared the RMSE against a baseline predicting the mean for every row, and stated whether the model adds value
- Documented the interpretation of results in Markdown

## Dataset

House price dataset

## Tools Used

Scikit-learn (LinearRegression) • Pandas • Jupyter Notebook
