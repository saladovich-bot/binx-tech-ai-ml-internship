# Day 1 — Environment Setup & Jupyter Workflow

## Learning Objectives

- Set up a reproducible Python environment using a virtual environment and pip
- Work fluently in the Jupyter Notebook cell-based workflow (code + Markdown)
- Initialize a Git repository and make a first commit of a working notebook

## What Was Done

- Created and activated a virtual environment (`venv`)
- Installed NumPy, Pandas, Matplotlib, and Jupyter
- Verified the setup by printing the installed version of each library
- Froze the environment to `requirements.txt`
- Committed and pushed the first notebook to GitHub

## Tools Used

Python 3.10+ • venv • pip • Jupyter Notebook • VS Code • Git & GitHub
