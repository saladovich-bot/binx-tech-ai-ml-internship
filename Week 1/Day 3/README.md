# Day 3 — NumPy: Numerical Computing

## Learning Objectives

- Create NumPy arrays in multiple ways and inspect their shape and dtype
- Index and slice 1D and 2D arrays, including boolean masking
- Use vectorized operations and broadcasting instead of Python loops

## What Was Done

- Created a 2D array of shape (4, 4) and inspected its shape and dtype
- Used slicing to extract specific rows and columns
- Applied a boolean mask to select values above the array's mean
- Used broadcasting to add a 1D row array to every row of a 2D array
