# Day 2 — Python for Data Science

## Learning Objectives

- Use Python's core data types and control flow fluently
- Write clean, reusable functions with clear parameters
- Write list comprehensions and read basic object-oriented code

## What Was Done

- Wrote a function returning the mean, min, and max of a list as a dictionary
- Rewrote a for-loop that filters even numbers as a single list comprehension
- Defined a small class representing a data record, with attributes and a method
- Documented each step with Markdown explanations
