# Day 5 — Matplotlib & Week 1 Integrated Mini-Notebook

## Learning Objectives

- Create labeled line, scatter, bar, and histogram plots
- Combine multiple plots into one figure using subplots
- Assemble a complete mini-notebook using NumPy, Pandas, and Matplotlib together

## What Was Done

- Loaded and cleaned a pulse/calories dataset with Pandas
- Used NumPy to compute summary statistics on the data
- Built a scatter plot exploring the relationship between Pulse and Calories burned
- Built a histogram showing the distribution of Maxpulse values
- Combined the histogram and scatter plot side by side in a single figure using `plt.subplots()`
- Labeled all axes and titles, and added Markdown notes interpreting each plot (e.g., a positive trend between pulse and calories, with a few outliers)

## Tools Used

Matplotlib • Pandas • NumPy • Jupyter Notebook • Git & GitHub
