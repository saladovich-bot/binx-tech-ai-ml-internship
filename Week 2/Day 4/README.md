# Day 4 — EDA Part 1: Distributions & Outliers

## Learning Objectives

- Explain why EDA is a required first step before modeling
- Perform univariate analysis using Seaborn histograms, box plots, and count plots
- Detect outliers using the IQR method and decide how to handle them

## What Was Done

- Produced a histogram for each numeric variable in the dataset
- Produced box plots for the key numeric variables and identified outliers visually
- Applied the IQR method in code to flag outliers in at least one column, and decided (with justification) how to handle them
- Produced a count plot for each categorical variable and noted any class imbalance
- Documented what each distribution reveals in Markdown cells

## Dataset

Real tabular dataset (Titanic)

## Tools Used

Seaborn • Pandas • Matplotlib • Jupyter Notebook
