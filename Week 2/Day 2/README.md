# Day 2 — Probability & Distributions

## Learning Objectives

- Apply the complement, addition, and multiplication rules of probability
- Explain conditional probability and Bayes' theorem, and where they appear in ML
- Recognize the normal, binomial, and uniform distributions

## What Was Done

- Simulated 10,000 coin flips with NumPy and confirmed the proportion of heads approaches 0.5
- Sampled from a normal distribution with `np.random.normal` and plotted a histogram to confirm the bell shape
- Worked through a small conditional-probability scenario by hand and verified the result with a simulation
- Documented each result with a Markdown explanation of what it demonstrates

## Dataset

Simulated data (coin flips, normal distribution samples) — no external dataset used

## Tools Used

NumPy • Matplotlib • Jupyter Notebook
